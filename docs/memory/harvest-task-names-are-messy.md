Harvest has ~90 active task names with heavy overlap — `Design`, `Design - Digital`, `Design - UX/UI`, `Graphic Design`, `UI/UX Design`, `UI Design concepts`, `Interface Design`, `Concept Designs`, `document design`, `EDMs / Graphic Design` all coexist. Leave and admin tasks sit in the same list as billable work.

**Why:** the list accreted since 2012 and was never rationalised.

**How to apply:** map task names to Services through `job-estimator/taxonomy.md`, never by judging at run time — run-to-run inconsistency defeats the point of the taxonomy. Exclude leave and admin tasks explicitly so they do not report as permanent gaps. Surface any unmapped name rather than guessing.
